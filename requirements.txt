# PopGMM pinned dependencies

# These are the exact versions that produced the committed `results/` tree.
# The pins are scientifically load-bearing, not hygiene:
#
#   * hdbscan is REQUIRED, not optional. scripts/hdbscan_filtering.py
#     (_make_hdbscan_estimator) imports python-hdbscan first and silently falls
#     back to sklearn.cluster.HDBSCAN when it is missing. The two backends do
#     not produce the same noise set, so an install without hdbscan yields a
#     different cohort. The committed run used hdbscan.hdbscan_.HDBSCAN.
#   * scikit-learn drives GaussianMixture with init_params="kmeans"; the KMeans
#     RNG stream and n_init defaults have changed across minor releases, which
#     moves the BIC-selected best_k and renumbers every component id.
#
# Reproducibility status of these pins: see docs/reproducibility_probe.md.
# Environment provenance: see docs/environment_snapshot.txt.
#

#   conda create -n popgmm python=3.12.6 && pip install -r requirements.txt
